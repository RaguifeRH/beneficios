Antes de importar: confira se as regras do Firestore permitem escrita nas coleções gp_movs, gp_mult, gp_motoristas, gp_auxedu e exp_data.
1. Movimentações internas
0 registros → coleção gp_movs
2. Prêmio multiplicadores
0 registros → coleção gp_mult
3. Motoristas (cesta / ticket)
0 registros → coleção gp_motoristas
4. Auxílio-educação
0 registros → coleção gp_auxedu
5. Efetivações (histórico da experiência)
0 registros → gravados em exp_data por correspondência de nome com os processos de admissão. Nomes sem correspondência são listados e ignorados (funcionários antigos sem processo de admissão no sistema).
